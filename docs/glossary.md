# Glossary — security-ai

Fachbegriffe, alphabetisch.

**ADR** — Architecture Decision Record. Siehe `adr/`.

**Audit** — Ereignis-Log im JSONL-Format.

**ChangeApplier** — Wendet Change-Objekte atomar an, mit Backup/Rollback.

**Detection** — Regelwerk, das Events klassifiziert.

**Inventory** — Momentaufnahme der Systembestandteile.

**OP-NNN** — Status-Punkt in `STATUS.md`.

**RBAC** — Rollen-basierte Zugriffskontrolle.

**Risk Engine** — Deterministische Bewertung von Events.
